# Getting help

- **Documentation:** [docs.tachyoncms.com](https://docs.tachyoncms.com), including the [security model](https://docs.tachyoncms.com/security-model)
- **Questions and ideas:** [GitHub Discussions](https://github.com/tachyon-cms/tachyoncms/discussions)
- **Bugs:** [open an issue](https://github.com/tachyon-cms/tachyoncms/issues/new/choose)
- **Security problems:** see [SECURITY.md](SECURITY.md). Please don't post them in public.

TachyonCMS is pre-alpha, so expect rough edges and the occasional breaking
change.
